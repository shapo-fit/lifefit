# הלוח של החבר'ה: הוראות העלאה (חינם)

זמן משוער: 20–30 דקות, פעם אחת. לא צריך לדעת לתכנת.

**מה יש בתיקייה**

| קובץ | מה הוא עושה |
|---|---|
| `index.html` | האפליקציה עצמה |
| `config.js` | הקובץ היחיד שצריך לערוך: כתובת ומפתח של Supabase |
| `supabase/schema.sql` | יוצר את הטבלאות וההרשאות במסד הנתונים |
| `manifest.webmanifest`, `sw.js`, `icons/` | מה שהופך את האתר לאפליקציה שאפשר להתקין ושנפתחת גם בלי קליטה |

---

## שלב 1: מסד נתונים ב-Supabase (כ-10 דקות)

1. נכנסים ל-https://supabase.com ובוחרים **Start your project**. אפשר להירשם עם חשבון GitHub או מייל.
2. בוחרים **New project**:
   - **Name:** משהו כמו `halooh`.
   - **Database Password:** סיסמה חזקה. שמור אותה, אבל האפליקציה לא צריכה אותה.
   - **Region:** הכי קרוב לישראל, למשל Frankfurt (Central EU).
   - לוחצים **Create new project** ומחכים כ-2 דקות.
3. **מריצים את המבנה:** בתפריט הצד בוחרים **SQL Editor** ואז **New query**.
   - פותחים את `supabase/schema.sql` בעורך טקסט (Notepad או TextEdit).
   - **מחליפים את `CHANGE-ME`** בקוד הצטרפות משלך, למשל `SHABAT-WOD-77`. זה הקוד שתשלח לחברים. מי שלא יודע אותו לא יכול להיכנס.
   - מעתיקים את כל הקובץ, מדביקים, ולוחצים **Run**. התוצאה אמורה להיות `Success. No rows returned`.
4. **מכבים אימות מייל.** בלי זה אף אחד לא יצליח להירשם, כי השרת החינמי של Supabase שולח רק 2 מיילים בשעה.
   - בוחרים **Authentication** ← **Sign In / Providers** (בגרסאות מסוימות: **Providers** ← **Email**).
   - מכבים את **Confirm email** ושומרים.
5. **מעתיקים את הכתובת והמפתח:**
   - בוחרים **Project Settings** (גלגל השיניים) ← **API Keys** או **Data API**.
   - מעתיקים את **Project URL** (נראה כמו `https://abcd1234.supabase.co`).
   - מעתיקים את המפתח הציבורי: **anon public** או **Publishable key**.
   - ⚠️ **לא** את `service_role` ולא את `Secret key`.
6. פותחים את `config.js` ומדביקים את שני הערכים במקום `YOUR-PROJECT...` ו-`YOUR-ANON...`. שומרים.

> המפתח הציבורי בטוח לפרסום. ההגנה על הנתונים היא בהרשאות שקובץ ה-SQL יצר: רק חברי הקבוצה רואים אימונים, וכל אחד יכול למחוק ולערוך רק את שלו.

## שלב 2: העלאה ל-GitHub Pages (כ-10 דקות)

1. נרשמים ל-https://github.com, אם עוד אין לך חשבון.
2. בוחרים **+** (למעלה) ← **New repository**:
   - **Repository name:** למשל `halooh`.
   - **Public**. GitHub Pages בחינם עובד רק עם repository ציבורי. הקוד יהיה גלוי, אבל הנתונים של החברים לא, כי הם ב-Supabase.
   - לוחצים **Create repository**.
3. בעמוד הריק בוחרים **uploading an existing file**.
4. גוררים לחלון את **כל התוכן של התיקייה**: `index.html`, `config.js`, `sw.js`, `manifest.webmanifest`, ואת התיקיות `icons` ו-`supabase`. ב-Chrome אפשר לגרור תיקיות. לוחצים **Commit changes**.
5. בוחרים **Settings** ← **Pages**:
   - **Source:** Deploy from a branch.
   - **Branch:** `main`, תיקייה `/ (root)` ← **Save**.
6. מחכים 1–3 דקות ומרעננים. למעלה תופיע הכתובת: `https://השם-שלך.github.io/halooh/`.

## שלב 3: בדיקה והפצה

1. פותחים את הכתובת **בטלפון** ← **הרשמה** ← שם, מייל, סיסמה וקוד ההצטרפות.
2. מתקינים:
   - **אייפון:** ב-Safari, כפתור השיתוף ← **הוסף למסך הבית**.
   - **אנדרואיד:** ב-Chrome, תפריט ⋮ ← **התקן אפליקציה**.
3. רושמים אימון אחד. אם הוא מופיע בפיד, הכול עובד.
4. שולחים לחברים את הלינק ואת קוד ההצטרפות.

## שאלות שיעלו

**חבר שכח סיסמה.** אין שליחת מייל לאיפוס (חסכנו את זה כדי שיהיה חינם). ב-Supabase: SQL Editor ← מריצים (מחליפים את המייל והסיסמה):
```sql
update auth.users
set encrypted_password = extensions.crypt('סיסמה-חדשה-123', extensions.gen_salt('bf'))
where email = 'friend@example.com';
```
ושולחים לו את הסיסמה הזמנית. אחרי הכניסה הוא מחליף אותה בעצמו: לשונית **שלי** ← **הגדרות** ← **סיסמה חדשה**.

**הפרויקט "הושהה" (Paused).** בתוכנית החינמית, פרויקט שאף אחד לא נכנס אליו שבוע מושהה. נכנסים ל-Supabase ולוחצים **Restore project**. הנתונים נשמרים.

**להחליף את קוד ההצטרפות.** SQL Editor:
```sql
update public.app_secret set join_code = 'קוד-חדש';
```
מי שכבר בפנים נשאר בפנים.

**להעיף מישהו.** Authentication ← Users ← שלוש נקודות ליד המשתמש ← Delete user. כל האימונים שלו נמחקים איתו.

**העלאת גרסה חדשה.** ב-GitHub: Add file ← Upload files ← גוררים את הקבצים שהשתנו ← Commit. **חשוב:** לפני ההעלאה מעלים ב-1 את `VERSION` בשורה 3 של `sw.js` (v1 ← v2), אחרת טלפונים עלולים להמשיך להציג את הגרסה הקודמת.

**אין קליטה בחדר הכושר.** אפשר לרשום כרגיל. האימון נשמר בטלפון, מסומן "ממתין לשליחה", ונשלח לבד כשחוזרת קליטה.
